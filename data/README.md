# Data

Raw datasets are not redistributed in this repository. Please obtain them from
the original sources listed in the root `README.md`, then place local files
under `data/raw/`.

Included here:

- `splits/*/{train,valid,test}.csv`: fixed splits used for the main results.
- `raw/`: local dataset placeholders; raw files are ignored by git.

Official P2C outputs and frame feature artifacts are stored under
`artifacts/`.
